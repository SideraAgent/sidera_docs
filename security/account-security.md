# Account security

Account security protects both your Sidera workspace and your trading infrastructure. Treat your Sidera account as a high-sensitivity system if it has live trading access.

## Basic security rules

- Use a strong, unique password if email login is enabled.
- Enable two-factor authentication wherever available.
- Keep wallet seed phrases offline and private.
- Do not sign wallet messages from unfamiliar domains.
- Do not share account access across team members unless Sidera provides controlled team permissions.
- Review connected wallets and credentials regularly.

## Wallet safety

When using wallet authentication:

- Confirm the domain before signing.
- Confirm the wallet address.
- Read wallet prompts carefully.
- Reject unexpected signature requests.
- Never enter a seed phrase into Sidera.
- Use hardware wallets for larger accounts when practical.

## Session safety

Use these habits:

- Sign out on shared devices.
- Avoid public Wi-Fi for live trading operations.
- Keep browser and wallet extensions updated.
- Remove unused browser extensions.
- Lock your computer when away.

## Suspicious activity

If you notice suspicious activity:

1. Disable live trading.
2. Revoke exchange API keys.
3. Disconnect wallets or rotate credentials where possible.
4. Change passwords.
5. Review decision logs and venue order history.
6. Contact support with timestamps and affected accounts.
